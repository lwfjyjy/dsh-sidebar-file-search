# dsh-sidebar-file-search

DSH 插件：在**右侧栏右上角那排图标（分屏 / 全屏 / 收起）左侧**显示一个「🔍 搜索 ⌘⇧K / Ctrl+Alt+K」小胶囊，点开是 **Vite 风格悬浮搜索窗**，按路径做**顺序模糊匹配**（例如输入 `acea` 也能命中 `abcdefg/abcdefg`），选中文件后在**右侧预览**打开，选中文件夹则**逐层下钻**。

## 特性

- ⚡ **毫秒级**：直接复用系统内置的 `@` 引用文件模糊引擎（`ctx.remote.fileReferences.list`），不自己扫盘、不存索引；输入防抖 120ms + 可取消旧请求。
- 🎯 **连续命中优先**：文件名里连续命中的结果排在“m…d 散落匹配”前面，高亮也优先整段连续匹配（如输入 `md` 高亮 `README.md` 末尾的 `md`）；没有连续命中时才退回顺序子序列匹配。
- ⌨️ **快捷键**：桌面端默认 `⌘⇧K`（Mac）/ `Ctrl+Alt+K`（Windows）；Web 版为避免和系统自带搜索的 `Ctrl+Alt+K` 冲突，Windows 回退为 `Ctrl+Shift+K`。经系统快捷键服务注册，不与内置 `⌘K`（自带搜索）冲突，也避开浏览器全屏键 `⌘⇧F`；`Esc` 关闭，打开即聚焦输入框。
- ⚙️ **可自定义快捷键**：搜索窗底栏右侧显示当前快捷键，点旁边的齿轮打开「快捷键设置」，按下新组合键即可保存（录制时按钮会**实时显示当前按下的键**；需带 ⌘/Ctrl、Alt 或 Shift 等修饰键），也可一键恢复默认；「完成」按钮使用 dsh 品牌色、与系统弹窗确认按钮一致；设置仅记在浏览器 localStorage，不改任何项目文件。
- 🎨 **符合 dsh 设计规范**：颜色 / 圆角 / 阴影全部走 `--dsw-*` 令牌，自动适配明暗主题。
- 🧭 **Vite 同款交互**：`↑ ↓` 切换、`↵` 打开、`Tab` 以 `@` 引用插入到输入框、`esc` 关闭，命中字符高亮；选中行右侧会提示「Tab 插入」。
- 🗂 **文件名优先 + 路径压缩**：每行先突出文件名，右侧用浅色显示压缩后的目录（过长时保留首段和末尾两段，中间用 `…` 省略），长路径不会再把文件名挤掉。
- 📐 **自适应窄栏**：右侧栏较窄时按钮自动收成「仅放大镜图标」，并给表头预留对应空白，保证任何宽度都不会压住 tab 标题。

## 目录

```
package.json       插件清单（纯前端 client 插件）
cordis.patch.yml   插入一条插件记录
index.js           Host 半边（空实现）
client.js          全部逻辑：右侧栏角标按钮 + 悬浮窗 + 快捷键 + 模糊搜索
icon.svg           插件图标
```

## 安装

作为 GitHub 资源加入 dsh profile：

```bash
pnpm add github:lwfjyjy/dsh-sidebar-file-search
```

再把包名加入 profile 的 `dsh.profile.bundles`，重载客户端后生效。

## 说明

- 搜索依赖系统的 `fileReferences` 能力（即输入框 `@` 引用的同一套引擎），因此结果范围 = 当前会话工作区，且要求会话已有 agent。
- 本插件不写任何文件到磁盘、不持久化索引。
